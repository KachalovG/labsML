# Anti Spam Model

Проект для лабораторной работы N 4 по применению методов машинного обучения в бизнес-задаче классификации SMS-сообщений.

## Суть задачи

Бизнес-задача: предварительно выявлять спам-сообщения, чтобы снижать риск фишинга и уменьшать нагрузку на ручную модерацию.

ML-задача: бинарная классификация текста:

- `0` - обычное сообщение (`HAM`);
- `1` - спам (`SPAM`).

## Важно

Модель в текущем отчете не переобучалась. Используются уже сохраненные артефакты:

- `src/model.pkl`
- `src/vocab.pkl`

Файл `src/train.py` оставлен как исходный код обучения, но при подготовке отчета не запускался.

## Структура

- `data/raw/spam.csv` - исходный датасет.
- `data/processed/spam_clean_fix.csv` - очищенный набор.
- `data/processed/data-for-fit.csv` - сбалансированный набор, использованный сохраненной моделью.
- `src/models/adaline_sgd.py` - реализация классификатора.
- `src/preprocessing/` - очистка и векторизация текста.
- `src/predict.py` - загрузка сохраненной модели и прогноз.
- `results/report_graphs/` - графики для отчета.
- `LR4_report_anti_spam_model.docx` - итоговый отчет.
