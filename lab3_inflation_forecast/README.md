# Лабораторная работа N 3. Прогноз инфляции с сезонной компонентой

Проект содержит код, данные, сохраненные артефакты моделей и итоговый Word-отчет для лабораторной работы N 3 по анализу временных рядов.

## Состав

- `data/inflation_long_format.csv` - исходный месячный ряд инфляции РФ.
- `data/data_processing.py` - подготовка признаков временного ряда.
- `train.py` - обучение моделей, расчет метрик, сохранение прогнозов.
- `models/` - реализации моделей и сохраненные артефакты.
- `report_assets/` - графики, использованные в отчете.
- `reports/ЛР3_Качалов_идеальный_отчет.docx` - финальный отчет.
- `build_lab3_ideal_report.py` - генерация финального DOCX-отчета.

## Модели

В работе сравниваются Linear Regression, Ridge, HuberRegressor, Gradient Boosting и baseline-модели. Итоговая модель выбрана по метрикам MAE, MSE, RMSE, R2 и MAPE.

## Отчет

В отчете отдельно указано, что по согласованию с преподавателем вместо Excel-реализации были построены модели в Python, при этом требования задания по сезонности, оценке точности и прогнозу сохранены.
